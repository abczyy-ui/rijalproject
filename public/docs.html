Dokumentasi API

Autentikasi

Semua endpoint memakai header Authorization: Bearer ACCESS_TOKEN. Token didapat dari login Supabase (session.access_token).

GET /api/stats

Menampilkan jumlah website ter-deploy dan sisa jatah hari ini.

curl https://DOMAINMU/api/stats -H "Authorization: Bearer TOKEN"

{"deployed":12,"today":2,"limit":5,"role":"user","username":"budi"}

POST /api/deploy

Mengirim file website ke Vercel. Respons berupa teks yang mengalir (stream) berisi log proses. Isi data dengan base64. Total ukuran maksimal sekitar 4,5 MB.

curl -N -X POST https://DOMAINMU/api/deploy \
 -H "Authorization: Bearer TOKEN" -H "Content-Type: application/json" \
 -d '{"name":"websiteku","files":[{"file":"index.html","data":"PGgxPkhhbG88L2gxPg=="}]}'

Kode status: 401 sesi habis, 429 jatah 5x per hari habis (admin tanpa batas), 400 tidak ada file.

POST /api/profile

Mengganti foto profil lewat URL gambar (http/https). Kirim string kosong untuk menghapus foto.

curl -X POST https://DOMAINMU/api/profile \\
 -H "Authorization: Bearer TOKEN" -H "Content-Type: application/json" \\
 -d '{"avatar_url":"https://contoh.com/foto.jpg"}'

Batas pemakaian

User biasa: 5 deploy per hari, reset pukul 00.00 WIB. Admin: tanpa batas.
